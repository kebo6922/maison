⚙ Configuration

🔥 Firebase (base de données partagée)

1. Créer un projet sur console.firebase.google.com
2. Realtime Database → Créer → Copier l'URL
3. Règles : mettre ".read": true, ".write": true
4. Project Settings → Config → Copier les valeurs ci-dessous

📧 EmailJS (alertes mail)

1. Créer un compte sur emailjs.com (gratuit — 200 mails/mois)
2. Add New Service → Gmail → Copier le Service ID
3. Email Templates → Créer un template → Copier le Template ID
4. Account → Public Key → Copier
